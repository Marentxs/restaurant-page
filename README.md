# Restaurant Page

🔗 **Live Demo:** (https://marentxs.github.io/restaurant-page/)

A multi-page restaurant website generated entirely using JavaScript modules and bundled with Webpack.

## Features
- Dynamic homepage, menu, and contact modules
- Navigation bar
- Webpack bundling & development server
- DOM manipulation
- Modular JavaScript structure

## Getting Started

### Clone the repository
git clone https://github.com/Marentxs/restaurant-page.git

### Install dependencies
npm install

### Run development server
npm start

### Build for production
npm run build

## Deployment
This project is deployed using GitHub Pages and the `gh-pages` branch created from the `dist` directory.
